# malevolent-shrine

This repository is a manifest set for [Shrine](https://github.com/CarlosHPlata/shrine) — it contains no application code itself, only `shrine/v1` YAML manifests that declare Teams, Resources, and Applications for deployment by the `shrine` CLI.

See the [Shrine manifest schema reference](https://carloshplata.github.io/shrine/reference/manifest-schema/) for the full field documentation of the three manifest kinds used here (`Team`, `Resource`, `Application`).

## Layout

| Path | Contents |
|------|----------|
| [`ops_bot.yml`](ops_bot.yml) | `Team` manifest for the `ops_bot` namespace. |
| [`ops_docs.yml`](ops_docs.yml) | `Team` manifest for the `ops_docs` namespace. |
| [`test.yml`](test.yml) | `Team` manifest for the `test` namespace. |
| [`ops/`](ops/) | `Resource` and `Application` manifests owned by the `ops_bot` and `ops_docs` teams. |
| [`test/`](test/) | `Resource` and `Application` manifests owned by the `test` team. |
| [`traefik/`](traefik/) | Traefik static/dynamic routing config generated by `shrine` for applications with `networking.exposeToPlatform: true`. |

## Teams

- **ops_bot** ([ops_bot.yml](ops_bot.yml)) — quota for 1 app / 1 resource.
  - [ops/ops_bot_app.yml](ops/ops_bot_app.yml) — `ops-bot` Application (Discord Tickets bot).
  - [ops/ops_bot_db.yml](ops/ops_bot_db.yml) — `ops-bot-db` Resource (Postgres 16).
- **ops_docs** ([ops_docs.yml](ops_docs.yml)) — quota for 3 apps / 10 resources.
  - [ops/ops_docs_ui.yml](ops/ops_docs_ui.yml) — `ops-docs-ui` Application (BookStack).
  - [ops/ops_docs_db.yml](ops/ops_docs_db.yml) — `ops-docs-db` Resource (MariaDB 11).
  - [ops/ops_excalidraw_front.yml](ops/ops_excalidraw_front.yml) — `ops-excalidraw-front` Application (ExcaliDash UI, nginx; published on `localhost:6767`).
  - [ops/ops_excalidraw_back.yml](ops/ops_excalidraw_back.yml) — `ops-excalidraw-back` Application (ExcaliDash API, SQLite in the `data` volume).
- **test** ([test.yml](test.yml)) — quota for 3 apps / 1 resource.
  - [test/aterrizar-backend.yml](test/aterrizar-backend.yml) — `aterrizar-backend` Application.
  - [test/externaldeps.yml](test/externaldeps.yml) — `aterrizar-externaldeps` Application.
  - [test/redis.yml](test/redis.yml) — `aterrizar-redis` Resource (Redis).

## Applying manifests

Teams must be registered before the Resources/Applications that reference them:

```bash
shrine apply teams
shrine deploy
```
